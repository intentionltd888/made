## 做法

1. **第一格**：GPT Image 2.5（high、1k、9:16），INTENTION 字標當參考圖，每支畫 2 張挑 1 張。挑的標準：字形和拼字完全正確、構圖真的置中對稱、看起來像手機拍的而不是電影。
2. **動起來**：Seedance 2.5、`omni_reference` 模式、第一格當 `start_image`、字標當 `image_references`、10 秒、有聲。先出 480p 草稿，挑最好的定稿成 1080p。Kling 3.0 pro 當備案（10 秒 20 點）。
3. **救字**：如果字在動態裡跑掉，用 Genjutsu 物件替換（`hf_mult_replace_object`），字標當參考圖把招牌換回正確的字。
4. **後製**（Higgsfield 雲端沙盒的 ffmpeg）：響度統一、輕微顆粒；需要時補一次急推。不加片頭片尾，保持像真的。
5. **發文**：平台規定寫實 AI 影片要標示；文案寫得像轉貼的目擊影片，但不要假裝是新聞。
